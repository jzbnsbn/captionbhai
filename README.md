# ✨ CaptionBhai

> Caption ka bhai, 10 second mein ready

AI-powered caption & hashtag generator for Instagram, TikTok & YouTube creators.

## 🎯 What it does

- 📷 Instagram captions + hashtags
- 🎵 TikTok captions + trending sounds
- ▶️ YouTube titles + descriptions + tags
- 🇮🇳 Hinglish, Hindi, English support
- 🆓 Free forever

## 🛠️ Tech Stack

- Frontend: HTML + Tailwind + Vanilla JS
- Backend: Python + FastAPI
- AI: Gemini + Groq + OpenRouter (fallback)
- Hosting: Render
